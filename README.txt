FILES

- checkout.html              Payment / checkout page
- assets/kumo-reboot.css     Visual redesign + animations
- assets/kumo-reboot.js      Scroll reveals, stagger, hero stage
- assets/logos/              SVG logo system

HOW TO OPEN
1. Keep the assets folder next to the HTML files
2. Open index.html in a modern browser
3. Add items → Bag → Checkout Now → checkout.html
4. Needs internet for Tailwind CDN + Google Fonts

CHECKOUT
- Cart is saved in localStorage (kv_cart)
- Shipping, contact, and payment form (demo only — no real charges)
- Free shipping over $50; standard / express options
- Card / PayPal / Apple Pay UI (simulated)
- Order confirmation overlay clears the bag
